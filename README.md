# Enterprise Network Design & Implementation

## 📌 Project Overview
This project focuses on designing, implementing, and configuring an enterprise network using Cisco Packet Tracer.

## 🛠️ Technologies & Concepts
- VLAN Configuration
- Inter-VLAN Routing
- DHCP Configuration
- Wireless Networking
- Network Address Translation (NAT)
- OSPF Routing
- Static Routing
- Basic Network Security

## 📂 Project Resources

- [Project Report](Enterprise-Network-Design-and-Implementation-Project.pdf)
- [Cisco Packet Tracer File](Enterprise-Network-Design-and-Implementation-Project.pkt)

## 🔍 Troubleshooting Experience
- Resolved VLAN assignment issues affecting network connectivity.
- Corrected an incorrect subnet mask on the wireless router.
- Troubleshot inter-VLAN routing issues.

## 🚀 How to Explore
1. Download the project report.
2. Download the Cisco Packet Tracer file.
3. Open the `.pkt` file using Cisco Packet Tracer.
4. Explore the network topology and configurations.

## 🎯 Learning Outcomes
Gained practical experience in enterprise network design, VLAN configuration, routing, network troubleshooting, and Cisco Packet Tracer simulation.
